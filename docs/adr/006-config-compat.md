# ADR-006: Совместимость конфигов

## Статус
Принято (2026-11)

## Контекст
`app_config.json` и `.pig/state.json` содержат много ключей, которые
пользователи уже настроили. Реструктуризация при миграции была бы
болезненной.

## Решение
Полная обратная совместимость: новый GUI читает и пишет **те же ключи**
в те же файлы. Никаких миграций, кроме одной — `theme`.

## Обоснование
- Пользователь обновляется без потери настроек
- Разработчик не пишет миграционный код на каждый ключ

## Последствия
- `gui_qt/config_compat.py`: `load_and_migrate` (читает, мигрирует
  `theme`) и `save_migrated` (пишет без устаревших ключей)
- Единственная миграция: `pink`/`eye_care` → `light`,
  `dark_pink` → `dark` (см. ADR-002)
- Ключ `ui_scale` удаляется при сохранении (не поддерживается)
- `ui_tree_expanded`, `ui_tree_unchecked`, `history_stack`,
  `redo_stack`, `excluded_paths` — формат без изменений
