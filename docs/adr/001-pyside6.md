# ADR-001: PySide6 как GUI-фреймворк

## Статус
Принято (2026-11)

## Контекст
Исходный GUI PIG-T3 написан на Tkinter (DarkApp). Требовалось перейти
на современный Qt-стек с поддержкой кастомных моделей данных
(QAbstractItemModel), QThread и стилей.

## Решение
Использовать **PySide6** — официальные привязки Qt 6 к Python (LGPL).

## Обоснование
- LGPL-лицензия совместима с MIT-лицензией проекта (динамическая линковка)
- Активная поддержка Qt Company
- Полный доступ к `QThread`, `QAbstractItemModel`, `QSS`, `QDialog`
- Доступны `pytest-qt`, `shiboken6` для тестов

## Последствия
- Зависимости: `PySide6>=6.6`, `qt-material>=2.14`
- Все новые вкладки/диалоги/модели — на PySide6 (см. `PIG_T3/gui_qt/`)
- Legacy Tkinter-код (`PIG_T3/gui/`) удалён в T-008
