## 🆕 Блок 5 — run_command (C6) — **НОВОЕ**

### Настройки

- [ ] **⚙️ → Функционал → «Выполнение команд (AI может запускать)»**
- [ ] Группа видна, 4 контрола: «Разрешить», «Подтверждать», «Таймаут», «Whitelist»
- [ ] Все **выключены** по умолчанию (opt-in)
- [ ] ✅ «Разрешить выполнение команд» → сохранить
- [ ] Проверка: `app_config.json` содержит `"allow_command_execution": true`

### Без opt-in (защита)

- [ ] JSON:
  ```json
  [{"action": "run_command", "command": "echo hi"}]
  ```
- [ ] «Просмотр изменений» → предупреждение «В патче 1 run_command, но в настройках не включено»
- [ ] «Применить» → `⛔ RUN заблокирован (allow_command_execution=false): echo hi`
- [ ] Команда **не** выполнена

### С opt-in — успешный сценарий

- [ ] ✅ «Разрешить» → JSON:
  ```json
  [
    {"action": "create", "path": "test_x.txt", "content": "hi"},
    {"action": "run_command", "command": "echo ok", "output_path": ".pig/cmd/x.log", "on_failure": "abort"}
  ]
  ```
- [ ] «Просмотр изменений» → **два пункта**: `➕ test_x.txt` и `▶ $ echo ok`
- [ ] Клик на команду → детали: `timeout: 120`, `output_path: .pig/cmd/x.log`, `on_failure: abort`
- [ ] «Применить» → `✅ RUN: echo ok (exit=0)`
- [ ] Файл `test_x.txt` создан
- [ ] Файл `.pig/cmd/x.log` создан, содержит `exit_code: 0` + `ok`

### Abort пайплайна

- [ ] JSON:
  ```json
  [
    {"action": "create", "path": "before_abort.txt", "content": "1"},
    {"action": "run_command", "command": "cmd /c exit 1", "on_failure": "abort"},
    {"action": "create", "path": "after_abort.txt", "content": "2"}
  ]
  ```
- [ ] «Применить» → `✅ CREATE: before_abort.txt` + `❌ RUN: cmd /c exit 1 (exit=1)` + `⏹ PIPELINE ABORTED`
- [ ] `before_abort.txt` **создан** (был до abort)
- [ ] `after_abort.txt` **не создан** (после abort)

### Timeout

- [ ] JSON: `{"action": "run_command", "command": "timeout /t 5 /nobreak", "timeout_sec": 1}`
- [ ] «Применить» → `❌ RUN ... (exit=-1, TIMEOUT)` через ~1 сек

### Whitelist

- [ ] Настройки → Whitelist: `pytest,ruff,git`
- [ ] JSON: `{"action": "run_command", "command": "echo hi"}`
- [ ] «Применить» → `❌ run_command: Команда 'echo hi' не входит в whitelist`
